## Project Overview

This project focuses on transforming raw transactional sales data into an interactive MIS dashboard using Microsoft Excel.

The dashboard provides insights into:

- Sales Performance  
- Revenue & Profitability  
- Regional Analysis  
- Product Performance  
- Monthly Growth Trends  

### 📊 Overall Performance Snapshot

| Metric | Value |
|--------|--------|
| Total Orders | 25,404 |
| Total Revenue | ₹6.22 Cr |
| Total Profit | -₹1.58 Cr |
| Profit Margin | -25.43% |
| Loss-Making Orders | 3,071 |
| MoM Growth | 4.07% |

## Data Cleaning & Preparation

To ensure accurate analysis, the following preprocessing steps were performed:

- Removed duplicate records  
- Handled missing/null values  
- Standardized date formats for monthly analysis  
- Matched and validated countries with corresponding cities  
- Corrected inconsistent regional entries  
- Verified revenue, cost, and profit calculations  
- Created calculated columns:
  - Profit  
  - Profit Margin (%)  
  - Month-over-Month Growth (%)  
- Structured cleaned data for efficient Pivot Table modeling  

These steps ensured reliable KPI generation and consistent reporting.

## Key Business Insights

- Strong revenue generation (₹6.22 Cr) but overall business loss of ₹1.58 Cr.  
- Negative profit margin (-25.43%) indicates pricing or cost inefficiencies.  
- North region generated the highest revenue.  
- All regions are currently operating at a loss.  
- 3,071 orders are negatively impacting profitability.  
- Positive MoM growth (4.07%) indicates gradual recovery trend.  

---

## Business Recommendations

- Review pricing strategy for low-margin products.  
- Reduce heavy discounting on loss-making orders.  
- Focus on margin optimization in high-revenue regions.  
- Encourage sales team to prioritize profitable sales.  
- Perform cost-structure optimization to improve margins.
